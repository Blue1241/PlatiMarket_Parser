# Plati Radar — Веб-интерфейс и парсер Plati.Market на Rust (`axum` + `tokio` + `reqwest`)

Полноценное веб-приложение в одном скомпилированном бинарнике Rust: ищет проверенные карточки товаров с большими отзывами, считает **реальную цену нужного тарифа** внутри мульти-карточек (разоблачая витринные цены за `GO`/пробники) и анализирует витрины продавцов.

## Структура проекта

- `Cargo.toml` — зависимости (`axum`, `tokio`, `reqwest`, `scraper`, `serde`, `clap`, `csv`)
- `src/main.rs` — HTTP-сервер `Axum`, API-эндпоинты и CLI-команды
- `src/ui.html` — веб-интерфейс (вшивается прямо в бинарник на этапе компиляции через `include_str!("ui.html")`)

## Как запустить у себя в VS Code

Открой папку `plati_rust_parser` в VS Code и выполни в терминале:

```bash
cargo run --release
```

После сборки сервер мгновенно поднимется на **`http://localhost:8080`** (порт можно сменить флагом `--port 3000`: `cargo run --release -- serve --port 3000`).

### Что умеет веб-интерфейс:
1. **Поиск выгодных карточек (`Deal Finder`):**
   - Быстрые пресеты (`ChatGPT Plus`, `Claude Pro`, `Spotify Premium`, `Xbox Game Pass`, `Telegram Stars`, `Пополнение Steam`) или любой свой запрос.
   - Фильтр по минимальному числу положительных отзывов, доле негатива и минус-словам (`оффлайн`, `общий`, `гайд`, `аренда`).
   - Глубокая проверка опций Digiseller: показывает **зелёную реальную цену тарифа** и подсвечивает красным бейджем накрутку относительно витрины.
   - Кнопка **«Все тарифы»** на любой карточке открывает всплывающее окно со всеми радиокнопками товара и точным расчётом цены в рублях без ухода со страницы.
   - Мгновенная сортировка, живой фильтр по словам (`без входа`, `на ваш аккаунт`, `код`) и выгрузка в **CSV (Excel)** / **JSON**.
2. **Проверка продавца:** разбор HTML-витрины любого магазина по ссылке или числовому ID (клик по имени продавца прямо из карточки товара автоматически открывает его статистику).
3. **База продавцов:** обход разделов `cats.xml` через официальный JSON API с обогащением HTML-витрин и экспортом в CSV.
